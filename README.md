# 群雄覇業｜六十余州制覇

ブラウザだけで動く、戦国シミュレーションです。サーバーもインストールも不要です。『信長の野望』の骨格に寄せて、リアルタイムの期と先行入力を組み合わせています。

A browser-only Sengoku (Warring States) simulation. No install. Open `index.html`, or run `python -m http.server` in this folder and visit the printed URL.

## できること

- **1期＝リアルタイム10分**（待ちきれなければ全員の「今期確定」で即時進行。試遊用に3分／1分／30秒／10秒も選べます）
- **方針の先行入力は100期分**（1期につき内政・外交・戦争・特殊・文化から最大3つ）
- **サブコマンドは各系統15**（合計75方針）
- **武将1000人**。うち **三国志演義のレア武将50人** は浪人として現れ、天才来訪や浪人登用で仕官します
- **国は令制国66**（いわゆる六十余州。戦国期の「国」の数に合わせています）
- **1〜6人**（同じ画面で家を切り替えて操作）
- **勝利条件**は国土（石高に相当する土地値）の **60％支配**
- **同盟・婚姻・不可侵・講和・宣戦**などの外交
- **天災・お恵み・天才来訪・お宝発見** が低確率で発生
- 資本は **米・お金・土地・兵士・民衆・文化度**

## 使い方

1. このフォルダの `index.html` をブラウザで開く  
   または、フォルダ内で次を実行して `http://127.0.0.1:8765/` を開く

```powershell
python -m http.server 8765
```

2. 人数と家を選び、開戦する  
3. 地図の国をクリックして対象を決め、方針を予約する  
4. 隣接する他領へ出陣し、国土の六割を目指す

進行状況はブラウザの保存領域にだけ残ります。

## ファイル構成

| ファイル | 役割 |
|---------|------|
| `index.html` | 入口 |
| `styles.css` / `app.js` | 画面 |
| `engine.js` / `data.js` | 期の進行・戦闘・外交・武将生成 |
| `assets/` | Wikimedia Commons から取得したフリー画像 |

## 画像について

`assets/` の写真・絵画は [Wikimedia Commons](https://commons.wikimedia.org/) のパブリックドメインまたはそれに準ずる作品です。詳細は `assets/CREDITS.txt` を見てください。武将の顔は家紋色の図柄で生成しています（千人分の肖像写真は使いません）。

## 注意

歴史上の家名・武将名を用いたフィクションです。史実の年月や勢力図を厳密に再現するものではありません。三国志演義の武将は「異国の豪傑」として登場するゲーム上の演出です。
